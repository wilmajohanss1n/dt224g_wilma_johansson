## Frågor om git
### Vad är skillnaden mellan git add och git commit?
Git add innebär att man förbereder och lägger till sina ändringar, medan git commit sparar dina ändringar permanent.
### Varför använder man branches istället för att jobba direkt i main?
Man använder branches för att kunna arbeta med ändringar utan att det påverkar den klara verisionen main, branches underlättar även samarbete med andra personer.
### Vad händer rent praktiskt när man gör en merge?
Merge slår ihop ändringar från en bransch till en annan bransch, tillexempel dev till main.
### Vad är skillnaden mellan att pusha till GitHub och att publicera direkt på t.ex. Netlify?
När man publicerar till Netlify blir webbplatsen live, vem som helst kan gå in och kolla på din webbsida. Medans push till GitHub så publiceras inte webbsidan automatiskt, koden laddas upp i en molntjänst.
### Om du vill exkludera någon fil i projektet från versionshanteringen, hur gör du då?
Man kan starta en fil som heter .gitignore. och lägga till filens namn som ska exluderas, då kommer filen inte vara med i verisionshanteringen.
